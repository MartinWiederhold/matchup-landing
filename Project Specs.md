# Project Specs

## What It Does
Content pipeline that takes one YouTube video and turns it into posts for LinkedIn, TikTok, Instagram, X, email, and Skool.

## Who Uses It
Me — one person running all content across 7 platforms.

## Tech Stack
- AI: Claude Code
- Data: Airtable
- Notifications: Slack
- Email: GoHighLevel

## Workflows
1. Pre-production — research topic, create content
2. LinkedIn — create post from youtube video
3. Short-form — create script from youtube video

## Data
- Airtable tracks every piece of content, and ideas
- Reference files store patterns, voice notes, and winning formulas

## What "Done" Looks Like
- One video → 10+ pieces of content across all platforms
